The rule is firm-specific, not universal

Some prop firms allow expert advisors, some prohibit them, and some allow them only on certain account types. The rule is usually in the prohibited-conduct section of the terms, not on the sales page. Before attaching an EA to an evaluation, search the terms for the words automated, algorithmic, expert advisor and latency. If the clause is ambiguous, ask support for a written answer that names your EA type.

Even where an EA is allowed, the strategy still has to respect the loss rules. An EA that opens positions without a hard stop can breach a daily loss limit faster than a manual trader because it does not hesitate. The evaluation is not a test of whether automation is permitted; it is a test of whether the automated method survives the rulebook.

Execution risks that only appear on a prop account

A prop account adds constraints that a personal account does not have: a maximum loss that ends the account, a daily stop that can halt trading, and a server that may be shared with other users. An EA that performs well on a demo can fail on a prop account because of slippage during news, a wider spread at the session open, or a latency spike that delays the stop. The strategy needs to be tested on the same platform and data feed the firm provides.

Run the EA on a demo with the firm's server settings, including the same leverage and contract specifications. Compare the realized slippage with the backtest assumption. If the difference is large, the live evaluation will be worse than the backtest regardless of the win rate.

Documentation before deployment

Write down what the EA does, which instruments it trades, the maximum risk per trade, the conditions under which it stops, and how it handles a news event. Keep the version of the code that produced the record. If the firm asks how a trade was generated, the documentation is the answer. An EA without a written specification is a black box that is hard to defend in a dispute.

If the firm prohibits automation, do not try to disguise it. The consequence is usually a breached account and a lost fee, not a warning. The rule exists because the firm is pricing a human trader's risk, and an automated strategy can change that risk in ways the terms do not allow.

Common questions

Are EAs allowed on prop firm accounts?

It depends on the firm and the account type. Some allow them, some prohibit them, and some restrict certain strategies. Check the prohibited-conduct section and get a written answer before deploying.

Can I run an EA on a VPS?

Only if the firm permits it and the VPS meets the platform requirements. A VPS does not change the trading rules, but it can change latency and execution quality.

What happens if an EA breaches a rule?

The account is usually closed or the payout is refused, even if the breach was unintentional. The firm applies the terms to the account, not to the intent behind the order.
