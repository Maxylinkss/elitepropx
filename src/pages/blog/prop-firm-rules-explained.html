Five categories, five different consequences

Prop firm rules fall into five categories: loss limits, profit targets, time conditions, conduct rules and payout conditions. Each category has a different consequence. A loss limit ends the account; a target moves it to the next phase; a time condition extends the calendar; a conduct rule can close the account or refuse a payout; a payout condition can reduce the amount that leaves the firm. A trader who treats all five as one list cannot prioritize.

The first step in reading any rulebook is to label each clause with its category. The second is to write the dollar value or the date that the clause implies. A rule that cannot be converted into a number or a date is not yet understood.

The definition is the rule

Two firms can use the same word and mean different things. A daily loss can be measured on balance or equity; a maximum loss can be static or trailing; a minimum day can require a closed trade or just a login; a consistency rule can apply to the evaluation, the funded account or only the payout. The definition is the rule, and the definition is usually in the terms page rather than the sales page.

When a clause is ambiguous, ask support for a written answer that quotes the terms. A reply that names the measurement, the reset time and the consequence is usable. A reply that says "it depends" is not. Keep the reply with the account records.

A reading order that saves money

Read the loss limits first, then the payout conditions, then the target and calendar, then the conduct rules, and finally the fees. The order follows the cost of getting it wrong. A misunderstood loss limit costs the account; a misunderstood payout condition costs the profit; a misunderstood fee costs money but is recoverable. Most traders read the target first because it is printed largest, which is precisely the wrong order.

After reading, rewrite the rulebook in your own words as a one-page checklist. If you cannot rewrite a clause, you do not understand it. The checklist is also the document to check before each session, which is when the rules actually matter.

Common questions

What is the most important rule to understand?

The loss limit, because getting it wrong ends the account. The definition matters as much as the number: static or trailing, balance or equity, and when the daily limit resets.

Where should I read the rules?

The firm terms page, not the sales page or a comparison article. If a clause is ambiguous, ask support for a written answer that quotes the terms.

Do all firms define daily loss the same way?

No. Some measure on balance and others on equity, and reset times differ. The definition changes the size you can safely trade.
