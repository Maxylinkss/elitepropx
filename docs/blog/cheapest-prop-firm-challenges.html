How this list was ranked

Discounts change the entry price, not the rulebook. A plan bought at 80% off carries the same loss floor and payout conditions as the full-price version, so the discount is only a bargain if the rulebook fits. The ranking below is built from the rulebook first and the price second, because a cheap evaluation attached to a rulebook that fights your method is not cheap at all.
