What this guide is really solving

FTMO Phase 1 Phase 2 Strategy is one of the decisions that sits between a trading method and a funded account. It changes how much you can risk, how quickly you can pass, or what a pass is worth after the fact, and it is usually decided by a clause rather than by the market. On an evaluation, the consequence is specific: the same decision either keeps the loss floor at a distance or brings the end of the account closer. The sections below turn that into a plan rather than a principle.

The frame matters because most prop-firm advice is written as if the only problem were finding a profitable strategy. It is not. An evaluation adds three constraints that a personal account does not have: a loss floor that ends the account, a calendar that may impose minimum days, and a payout condition that can reduce a profit after the pass. A method that ignores those constraints can be profitable in a demo and still fail the evaluation.

The rest of this guide works through those constraints in the order they bind: the loss floor first, because it decides position size; the target second, because it decides how many trades the plan needs; the calendar third, because it decides whether the plan is feasible; and the payout conditions last, because they decide whether a pass is worth anything. Each section ends with a rule that can be written down and checked.

Phase one is for proof, phase two is for repeatability

FTMO's first phase asks for the target with a static floor and a daily stop. The second phase asks for the same target again. The mistake is to treat phase two as a victory lap and increase size because the first phase worked. The rulebook has not changed, but the trader's confidence has, and confidence is the most common cause of a phase-two breach.

The correct transition is to keep the same risk unit and the same setup filter, and to change only the pacing. Phase one may have taken three weeks; phase two should be planned over a similar window, not compressed into a week because the account is "already proven". The proof is the process, not the speed.

A phase-by-phase risk budget

On a $100,000 account with a 10% maximum loss and a 5% daily stop, the total budget is $10,000 and the daily budget is $5,000. A 0.5% risk unit is $500, so the day can absorb ten losses and the full attempt twenty. In phase one, use the first half of the calendar to build a cushion of 3% to 4%; in phase two, use the same unit and the same daily stop. The target is the same, so the arithmetic is the same.

The phase transition is a good moment to review the journal, not to change the method. Count the setups taken, the win rate, the average winner and the average loser. If the expectancy is positive and the risk was within the budget, the process is working. If the result came from one oversized winner, the process is not proven; phase two is the place to test it again with the same size.

The verification phase and the payout

After the two evaluation phases, FTMO runs a verification phase. The target and the floor still apply, and the calendar extends. A trader who planned for two phases should add the verification period to the schedule before buying. The payout stage has its own season and conditions, so the first withdrawal is not immediate even after the verification.

If the strategy needs a fast payout, FTMO's sequence is the wrong product. If the strategy can wait and the rulebook fits, the sequence is a clear, documented path. The decision should be made before the first trade, not after the target is reached.

Common questions

Should I increase size in phase two?

Usually not. The rulebook is the same and the target is the same. Keeping the risk unit stable preserves the process that passed phase one; increasing size turns phase two into a different test.

How long should each FTMO phase take?

There is no required speed, but a plan that spreads the target over several weeks is more robust than a compressed sprint. The verification phase and payout seasoning should be added to the calendar.

What if phase one was profitable because of one big trade?

Treat the result as unproven and repeat the process in phase two with the same size. A single oversized winner is not evidence of a repeatable edge.
