Prop Firm News Trading Rules

News rules restrict opening or holding positions around scheduled releases. The restriction exists because a release can gap past a stop, which turns a planned loss into an unplanned one and can breach a daily limit in a single tick. This guide turns the rule into something you can apply to the plan you are actually trading.

Key takeaways

  • Being flat before the window is safer than relying on a stop.
  • The affected window is defined by the firm, often around major releases only.
  • Where news trading is allowed, size the event like an event rather than like an ordinary setup.

News rules restrict opening or holding positions around scheduled releases. The restriction exists because a release can gap past a stop, which turns a planned loss into an unplanned one and can breach a daily limit in a single tick. The consequence is always numerical. A rule changes the dollar value of a stop, the number of trades a day can absorb, or the amount that reaches a payout. Reading it as a number rather than a slogan is what makes it usable.

The window is the rule

News trading restrictions are usually time-based: a window before and after a scheduled release during which new positions are prohibited or existing positions must be closed. The window can be five minutes, fifteen minutes or longer, and it can apply to all instruments or only to the one affected by the release. The first step is to find the exact window and the list of covered events in the plan terms.

A restriction on opening a position is not the same as a restriction on holding one. Some firms allow a position to remain open through the release but prohibit opening or increasing it inside the window. Others require the position to be flat before the event. The difference decides whether a swing trader can hold overnight or has to close before every major release.

The gap risk the rule is trying to price

A news release can move price through a stop with no trading in between. The firm's loss limit is based on the account, not on the order, so a gap that jumps past the stop can produce a loss larger than the planned risk. That is why the rule exists: it limits the firm's exposure to an event it cannot hedge. A trader who ignores the rule is not just breaking a term; they are taking a risk the plan did not price.

The practical response is to reduce size before a scheduled event and to avoid holding a position that depends on a stop being filled at a specific price. If the strategy needs news exposure, use a smaller size and a wider stop, and confirm that the plan allows the position to be held at all.

Building a news calendar into the plan

Mark the red-folder events for the instruments you trade at the start of each week. For each event, decide whether the plan requires flat, allows holding, or prohibits new entries. Then set the session plan around that decision: no new entries in the window, a smaller size before the event, or a full stop for the day. Write the decision down before the event, because the moment the release prints is not the moment to interpret a rule.

If the rule is ambiguous, ask support before the trade, not after. A written answer is the only thing that will help in a dispute, and it is easier to get before the account is at risk.

Common questions

Does the news rule apply to all instruments?

It depends on the firm. Some restrict only the instrument affected by the release, while others apply the window to all positions. Check the plan terms for the covered events and instruments.

Can I hold a position through a news event?

Only if the plan permits it. Some firms require the account to be flat before the event, while others prohibit new entries but allow an existing position to remain.

What happens if a gap jumps past my stop during news?

The fill can be worse than the stop price, and the loss can exceed the planned risk. That is why the rule exists and why size should be reduced before a scheduled event.
